Troubleshooting

If your device doesn’t appear, check your USB serial drivers and ad blocker.

Boot mode for newer ESP32 boards

If the first installation fails on an ESP32-C3, C5, C6, S2, S3 or S31, try entering download mode before installing:

  1. Press and hold BOOT.
  2. Press RESET while holding BOOT.
  3. Release BOOT after the device reconnects over USB.
  4. Click the install button again.

If Wi-Fi setup doesn’t appear after installing the Full firmware, press RESET and reopen the installer.
Alternatively, you can configure the device’s Wi-Fi directly from Firefly Luciferin.

USB serial permissions on Linux

On most distributions, add your user to the dialout group:

sudo usermod -aG dialout "$USER"

On Arch Linux, use the uucp group:

sudo usermod -aG uucp "$USER"

Log out and back in for the change to take effect. If you installed Firefly Luciferin as a Snap, grant it USB access:

sudo snap connect fireflyluciferin:raw-usb
